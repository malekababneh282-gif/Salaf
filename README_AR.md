# سلف فورية — لوحة الإدارة CMS (نسخة تطويرية)

هذه النسخة مبنية على مشروع Salaf الحالي، وتحتفظ بجدول `loan_inquiries` وجدول `site_settings` الحاليين. لا تحذف بيانات الطلبات القديمة.

## ما تتضمنه هذه النسخة
- واجهة عربية للميني آب تقرأ إعدادات الموقع من Supabase.
- لوحة ويب على `/admin` باسم مستخدم وكلمة مرور.
- إدارة الطلبات والحالات والإحصائيات وسجل نشاط إداري.
- تعديل الاسم والوصف والشعار كرابط والألوان والخط.
- تعديل خانات النموذج الأساسية والإضافية.
- بوت المجموعة مع أزرار إحصائيات وآخر الطلبات وفتح الطلب وتغيير حالته.

## متغيرات Render المطلوبة
احتفظ بمتغيرات Supabase وTelegram الحالية، وأضف:
- `ADMIN_USERNAME`
- `ADMIN_PASSWORD`
- `ADMIN_PANEL_SECRET` (قيمة عشوائية طويلة لا تقل عن 32 حرفاً)
- `PUBLIC_SITE_URL` (رابط الخدمة، مثل `https://salaf-0zmu.onrender.com`)

لا تضع أي مفاتيح أو توكنات داخل GitHub أو ملفات الواجهة، ولا ترسلها لأحد.

## ترقية قاعدة البيانات
1. خذ نسخة احتياطية من Supabase أولاً.
2. راجع `SUPABASE_CMS_MIGRATION.sql` وشغّله مرة واحدة في SQL Editor.
3. الترقية تضيف `custom_fields` إلى `loan_inquiries` و`settings_json` إلى `site_settings` وتنشئ `admin_audit_log`. لا تحذف صفوف الطلبات الموجودة.

## النشر
- ارفع ملفات النسخة إلى نفس مستودع GitHub وفرع `main` مع الحفاظ على متغيرات Render.
- لا تحذف أو تعيد إنشاء خدمة Render أو مشروع Supabase.
- بعد إضافة متغيرات الإدارة وترقية قاعدة البيانات، نفّذ Deploy.
- لوحة الإدارة: `/admin`.
- فحص الخدمة: `/health`.
- Webhook: `/telegram/webhook` مع `TELEGRAM_WEBHOOK_SECRET`.

## إعداد Webhook
بعد التأكد من نشر الخدمة، اضبط Telegram `setWebhook` على:
`https://salaf-0zmu.onrender.com/telegram/webhook`
واستخدم `secret_token` المطابق تماماً لقيمة `TELEGRAM_WEBHOOK_SECRET` في Render.

## حدود النسخة الحالية — اقرأ قبل النشر
- هذه نسخة تطويرية أولى وليست نظاماً نهائياً مختبراً على قاعدة بياناتك الحية.
- تسجيل الدخول الحالي بحساب إداري واحد عبر متغيرات البيئة؛ إدارة عدة حسابات وصلاحيات موظفين غير منفذة بعد.
- حقل الشعار يقبل رابط صورة؛ رفع الصور مباشرة وتخزينها في Supabase Storage غير منفذ بعد.
- منشئ النماذج يسمح بإدارة الخانات العامة، لكن حقول الاسم والهاتف والموافقة الأساسية يجب أن تبقى ولا تُحذف لأن تخزين الطلبات يعتمد عليها.
- محرر النصوص متعدد اللغات، المعاينة/النشر المرحلي، استرجاع إصدارات الإعدادات، وإدارة كل أزرار البوت من واجهة مرئية تحتاج استكمالاً.
- النموذج الحالي يتطلب فتحه من Telegram Mini App للتحقق من `initData`.
- لا تجمع كلمات مرور أو بيانات بطاقات أو رموز تحقق. وضّح أن الخدمة مستقلة ولا تمثل مصرفاً ولا تضمن الموافقة أو صرف تمويل.

## اختبار ما قبل الإنتاج
اختبر تسجيل الدخول، تحميل الطلبات القديمة، تغيير حالة طلب تجريبي، حفظ إعدادات الموقع، إرسال نموذج تجريبي من Telegram، وأزرار البوت. لا تنشر للزوار قبل نجاح هذه الاختبارات.
